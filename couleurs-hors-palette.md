# Vermillon — couleurs utilisées hors colors.toml

| Usage | Hex |
|---|---|
| Fond des images (fonds d'écran, verrouillage, déverrouillage disque) | `#e8431c` |
| Accent (identique à colors.toml) — aussi clavier Wooting | `#ff4a1c` |
| Accent foncé (petits textes d'accent sur fond crème, ex. en-tête de notification) | `#c2340f` |
| Crème (texte sur les images) | `#f1e7d6` |
| Noir (disque, champs) | `#121010` |

## Déverrouillage du disque (Plymouth)
- Logo : `unlock.png` (logo Moozy)
- Couleur de fond : `#e8431c`
- Couleur du texte : `#121010`

## Menu de démarrage (Limine)
Voir `boot/limine.conf` : bloc prêt à coller (clés Limine 12.9.4, hex sans #).
À régler une seule fois, sur le thème principal.
